# Email Sender Bot 📧

## Overview
Email Sender Bot is a Python-based application that allows users to send emails automatically. It uses Python's SMTP library to connect with an email server and send messages to the receiver.

## Features
- Send emails automatically using Python
- Simple and user-friendly program
- Uses SMTP protocol for email delivery
- Fast and easy email sending process

## Technologies Used
- Python
- SMTP Library
- Email Module

## How It Works
1. Enter the sender email details.
2. Provide the receiver email address.
3. Enter the message content.
4. The bot connects to the email server and sends the email.

## Requirements
- Python installed
- Internet connection
- Email account with app password enabled
